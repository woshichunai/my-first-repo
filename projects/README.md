# 小项目与实验

有实际实践时再开始一个项目。可以是课程小实验、一个计算程序，或用表格分析一次测量结果。

## 何时新建项目

有一个明确问题、一个能展示或检查的结果，就可以开始。先选一两次学习时段内能做完的内容。

## 如何存放

在本目录新建简短英文或拼音文件夹，例如 `temperature-analysis/`。每个项目先放一份 `README.md`，写清：

1. 目标：想解决什么问题。
2. 方法：使用了什么材料、工具或步骤。
3. 结果：得到什么；附自己的数据、图片或运行方式。
4. 验证：如何判断结果是否正确。
5. 下一步：只保留一个改进动作。

确实需要代码、图片或数据时再放入该项目文件夹；没有代码也可以记录实验。不要为了建目录提前安装工具。
