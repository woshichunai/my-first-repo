# 我的第二大脑：本地收件箱 V1

把零散通知变成能查到、能执行的任务。Windows 本地桌面程序，只依赖 Python 标准库，不需要 Docker、服务器、模型 API 或付费服务。

## 开始使用

1. 下载本仓库 ZIP 并解压（仓库首页 Code → Download ZIP）。
2. 电脑需安装 Python 3.10+，包含 Tcl/Tk；已有 Python 可直接继续。
3. 打开 `projects/second-brain`，双击 `start.cmd`。首次若提示缺少 Python，前往 https://www.python.org/downloads/windows/ 安装。
4. 在窗口粘贴一条真实通知，点“保存原文”。可接连保存多条。
5. 点“复制给GPT”，粘贴到你的 ChatGPT 对话。若通知只有截图，先让 GPT 提取文字，再保存到这里。
6. 将 GPT 返回的 JSON 粘回窗口，点“导入GPT结果”，检查日期和任务是否正确。
7. 任务做完后选中并点“标记完成”。日期未知的任务显示“待确认”；已过期未完成的任务显示红色。

重新打开程序仍保留数据。“导出日历”生成 `.ics` 全天事件，需要自行导入日历；它不是提醒事项同步，也不会自行发送推送。重复导入同一个日历的行为由日历客户端决定。

## 数据与备份

- 默认保存位置：Windows 用户目录下 `SecondBrain/brain.sqlite3`，与公开代码仓库分离。
- “备份JSON”导出所有原文和任务（含完成项）。恢复时保留原数据库文件，并将备份数据库复制回同一位置；JSON 目前用于查看或迁移，未实现一键恢复。
- 换电脑前关闭程序，复制整个 `SecondBrain` 文件夹。也可设置环境变量 `SECOND_BRAIN_HOME` 指定私密数据目录。
- 原文不会上传；只有你主动把整理请求粘贴到 ChatGPT 时，相关文字才进入对话。
- 没有内置模型调用，不产生模型 API 费用；通过现有 ChatGPT 对话人工中转。
- 重复导入完全相同的整理结果会去重；同一通知被GPT换一种措辞重新生成，可能仍产生重复任务，需要人工核对。

## 当前边界

已实现：文本收集、本地持久化、GPT交接、结果校验、任务排序、完成记录、日历导出、备份。

未实现：微信/QQ后台采集、自动OCR、手机电脑同步、常驻自动执行、系统推送、模型自动调用。不要将“代码已提交”当作“已经安装到你的电脑”。

## 测试

在此目录运行 `python -m unittest -v`。覆盖重复导入、重启持久化、错误输入整批回滚、来源校验、未知日期不进日历、完成状态、UTF-8日历折行和备份。
