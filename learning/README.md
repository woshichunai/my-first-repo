# 学习记录

## 分类与命名

| 目录 | 内容 | 文件名示例 |
| --- | --- | --- |
| `advanced-math/` | 高数概念、典型题、错题反思 | `2026-11-01-limits.md` |
| `linear-algebra/` | 线代定义、运算、几何理解 | `2026-11-01-matrices.md` |
| `english/` | 阅读、词句、听力和表达 | `2026-11-01-reading.md` |

目前只建立有首篇记录的高数目录。线代、英语在保存第一条记录时创建，避免维护空目录。

## 一次记录的最小流程

1. 从[模板](../templates/learning-record.md)复制内容。
2. 按当天实际学习内容创建文件，标题用中文，文件名用简短英文或拼音。
3. 至少填写：一个收获、一个卡点、一个可执行的下一步。
4. 提交保存；下次复习时回来补充验证结果。

同一天不同主题可以分开记录。不要为了整理笔记重新抄整章教材。

## 复习标准

能不看笔记解释一个概念，或者独立完成一道同类题，再标记为“已验证”。英语可用“独立理解原句并自己造句”验证。
