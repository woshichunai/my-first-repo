# 第二大脑当前状态与下一步

更新：2026-11-03。

## 最新方向

主入口改为 **QQ 私人助理**：转发通知与课件 → 自动提取/归档 → 多次手机提醒 → 日程安排与手机可视化。
详细需求、技术路线与验收标准见 [QQ_ASSISTANT_PLAN.md](QQ_ASSISTANT_PLAN.md)。

原有手动复制 JSON 的本地收件箱保留作原型和数据层参考，不再要求先使用它才能推进QQ入口。

## 已完成与未完成

- 已完成：学习模板；本地桌面收件箱代码；三项核心自动测试；QQ助理需求与项目调研。
- 未实测：原有 Windows GUI 在用户电脑运行。
- 未部署：QQ接口、AI自动处理、Bark推送、文件自动归档、手机日历与排程、常驻服务。
- 既有每周效率推进安排保持原状；不把它当作QQ助理的截止提醒。

## 下一次接手

1. 先读 QQ_ASSISTANT_PLAN.md，不重复从零讨论，也不把“已提交代码”写成“已部署”。
2. 根据用户的设备与预算选运行位置。先验证QQ文本、图片、文件和合并转发，再选择官方机器人或备用QQ桥接。
3. 首次交付必须有：收到真实转发、课件可找回、手机锁屏收到测试推送、完成任务后取消后续提醒。
4. 排程留到课表/作息可用后接入。模糊截止时间先追问。
5. 所有私人原文、课件和凭据保存在私密数据目录；公开仓库只保存代码和脱敏说明。

## 原有调研项目

Memos、思源笔记、n8n 暂作为可选组件。现阶段优先减少组件数量，跑通QQ入口、文件归档和可靠提醒，不同时搭建多个知识库。
