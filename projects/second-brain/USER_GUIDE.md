# 使用指南

适用于 2026-11-04 的本机试用版本。命令发到已绑定的本人机器人私聊，参数之间使用空格。先读[能力边界](BOUNDARIES.md)。

## 1. 启动

电脑保持联网、插电、不休眠，打开 AstrBot；iPhone 开启 Bark 通知。ChatGPT 聊天窗口无需一直打开。开机自动启动尚未配置，重启电脑后需打开 AstrBot 并确认机器人能回执。

GitHub 页面只是代码与说明，打开页面不会启动服务。

## 2. 转发文字

直接发送或逐条转发纯文字。机器人先回复“原文已收到”和收件编号，再返回提取结果、任务编号与必要疑问。提取约需十几秒，也可能超时。

核对标题、年月日和具体时分。“周五晚上”“明天交”等模糊时间不会自动填成明确截止时间。

**目前不能只回复一个时间来关联上条任务。** 补充日期时，重新发送包含完整通知与完整截止日期时分的一条文字；确认新任务后，用 `完成 旧任务编号` 结束旧任务，避免旧提醒继续。自动更正与合并尚未接通。

## 3. 设置手机提醒

提取截止时间与设置提醒是两件事。没有默认的“提前三天、一天、两小时”策略，需要为每个任务明确指定。

格式：`提醒 任务编号 时间1 时间2`。每次 1 至 10 个未来时间，使用北京时间并带 `+08:00`。

假设回执编号为 `aaaaaaaaaaaa`，且下列日期仍在未来：

```text
提醒 aaaaaaaaaaaa 2026-11-06T18:00:00+08:00 2026-11-06T21:00:00+08:00
```

以上是格式示例，没有创建真实提醒。实际使用时替换编号和时间，过期日期不可照抄。

等待“已保存”回执，再发送 `任务 实际任务编号` 查看计划。再次设置同一任务会替换旧的未发提醒，已发通知不会撤回；时间不合法不会清空旧计划。

通知由 Bark 发出。服务接受不等于手机实际显示；权限、专注模式、网络会影响到达。投递未知时不会盲目重发。

## 4. 完成与延期

完成后发送 `完成 实际任务编号`，等待回执；尚未发出的提醒会取消。目前不要只说“完成了”，它不会可靠地修改任务。

延期时先完成旧任务，再发送含新截止时间的完整通知，取得新编号并重新设置提醒。自然语言延期和自动重排尚未实现。

## 5. 课件保存与找回

截图或 PDF 作为附件单独发送。只有“已下载并保存”才表示归档成功；“原文已收到”不等于附件已下载。

保存文件编号，找回时发送 `取回 实际文件编号`。文件编号和任务编号不可互换。

单个附件上限 20 MB。PDF、JPEG 截图已真实验证；PNG/WebP/PPTX 有类型检查代码，尚未逐项完成真实 QQ 验证。章节不明放待分类目录。同内容原件去重，但重发通知可能产生多个任务。

目前不自动 OCR、不读取 PDF/PPTX 正文、不自动分类。合并转发尚未验证，请将重要文字和附件逐条发送。

## 6. 故障处理

| 现象 | 处理 |
| --- | --- |
| 没有任何回执 | 确认本人已绑定机器人私聊，检查 AstrBot 和网络 |
| 模型超时、限额或暂不可用 | 原文保留；发送 `重试收件 收件编号` |
| 附件未归档 | 重新发送附件，核对类型与大小 |
| 找回失败 | 核对文件编号；原件缺失、校验失败或 QQ 发件失败也会导致失败 |
| 手机没有通知 | 查询任务计划和状态，检查手机通知/专注模式、网络；不要反复启动测试 |

反馈时提供现象、时间与脱敏错误文字，不发送账号密钥、Bark 地址、令牌或含密钥的截图。

## 7. 测试

`连接测试 测试任务编号` 仅用于明确标记为测试数据的任务，安排 30/90/180 秒三条提醒；第二条后发送 `完成 测试任务编号` 取消第三条。日常任务使用明确提醒时间。

本轮“高数第三章作业”是合成测试，已完成，第三条已取消，不是真实课业。
