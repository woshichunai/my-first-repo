# 能力与使用边界

更新：2026-11-04。未来目标见 [ROADMAP.md](ROADMAP.md)。

| 能力 | 当前范围 |
| --- | --- |
| QQ 入口 | 只处理已绑定本人的官方机器人私聊，不接管主号，不采集群聊或整个 QQ |
| 文字 | 保存原文，通过已有 ChatGPT 订阅 Codex CLI 提取；模糊时间待确认 |
| 文件 | PDF、JPEG 截图真实下载、哈希检查、归档和 QQ 找回通过；20 MB 上限 |
| 任务 | 本机持久化，按明确编号查询、设置提醒、完成取消 |
| 通知 | Bark 实测；用户针对本轮锁屏核对回复“收到”；第三条完成取消已复查 |
| 可靠性 | 数据库重开恢复、漏发合并、替换计划取消、未知投递不盲重发有测试；整机重启未实测 |

## 暂时不能做

- 自动 OCR、读课件正文、识别学科和章节。
- 保证 PPTX、PNG、WebP、合并转发都能在 QQ 正常收发；这些未逐项实测。
- 理解“完成了”“延期到周六”“今晚没空”并自动关联、改期、重排。
- 自动读取微信、群聊或历史聊天，替用户向同学老师发消息。
- 自动生成课表、学习安排、手机日历或看板。
- 电脑关机、休眠或退出 AstrBot 后继续工作；尚无开机自动恢复。
- 保证任何网络下必达、一键备份恢复或直接迁移到另一台电脑。

## 数据去向

| 数据 | 去向 |
| --- | --- |
| 转发文字和附件 | 经腾讯 QQ 通道，到本机 AstrBot 私密目录 |
| 用于提取的文字 | 由 Codex CLI 发到现有 ChatGPT 订阅对应的 OpenAI 服务，不是纯离线处理 |
| 图片与课件内容 | 当前只下载归档，尚未接入模型正文解析 |
| 手机提醒标题、任务内容 | 经 Bark api.day.app 及手机推送链路；锁屏预览由手机设置决定 |
| 代码、指南、脱敏验收摘要 | 公开 GitHub 仓库 |
| 账号密钥、QQ 会话标识、设备地址、原始课件聊天和数据库 | 留在本机，不上传 GitHub；设备推送密钥用 Windows 当前用户加密保存 |

## 自动化与运行条件

消息和附件是资料，不是管理员指令。本人身份由程序核对；模型仅负责提取字段。模型调用采用受限工具配置和结构化校验，异常结果不导入；这不等于正式安全审计或绝对隔离保证。

已确认的提醒由持久化队列投递，不依赖模型继续可用。提取到截止时间不会自动设置提醒，没有全局默认提醒策略。

使用现有电脑与现有 ChatGPT 订阅，未新增服务器、订阅或另计费模型 API。登录、额度和网络可能变化，不保证永久可用。

GitHub 保存程序和文档，不托管机器人、私密数据库或课件。更新 GitHub 不会自动更新本机运行的插件，必须单独部署和验收。旧桌面原型与 QQ 助理数据独立，不可混用状态与备份说明。
