# 自动化学习与项目记录

一个大一自动化学生的学习入口。先把学过的内容、卡住的问题和做过的小项目留下来，再逐步积累。

## 当前重点

1. 高等数学：理解概念，记录典型题和易错点。
2. 线性代数：理清定义、运算与几何意义。
3. 英语：积累能复用的词句与阅读方法。
4. 自动化相关实践：有实际小实验或程序时再记录，不额外安排复杂路线。

## 从这里开始

打开[首篇高数记录](learning/advanced-math/2026-10-31-first-record.md)，填写今天实际学到的一个知识点、一处卡点和一个下一步，然后保存提交。

以后需要新记录时：

1. 打开[模板](templates/learning-record.md)，复制内容。
2. 在对应学科目录新建文件，命名为 `YYYY-MM-DD-topic.md`。
3. 填写后提交，提交说明例如：`docs: 记录极限定义的一个疑问`。

可以直接用 GitHub 网页编辑 Markdown；无需先安装编辑器、插件或构建工具。

## 保持可持续

- 每周至少留一条有用的记录，不强求每天打卡。
- 一次只写一个主题；忙时只填“学到了什么、卡在哪里、下一步”。
- 复习时在原记录补充纠正和验证结果，保留思考过程。
- 只有出现实际内容时才增加目录、工具或项目。
- 本仓库公开：只放自己的学习总结；不上传密码、订阅链接、个人信息、同学聊天或未获授权的课程资料。
